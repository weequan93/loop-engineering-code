# Development scenario entrypoint

For this project's development work, first read `.loop/start.md` and
`.loop/workflow.md`. The role roster is `.loop/scenario.json`; the user's
requirements are `.loop/spec.md`. The coordinator prepares tasks and manages
specialists so the user can describe requirements and answer questions in
ordinary language. Preserve existing repository instructions and user work.

When the roster declares it, read `.loop/agent-protocol.md` and the selected
role's professional procedure. Current coverage assignments also supply the
covered contracts; keep their findings and requirement coverage explicit.

Read `LOOP.md`, the current `.loop/task.json`, recorded questions/answers and
the handoff. Follow the host's actual permissions. Role files are workflow
instructions, not permission grants or evidence of agents having run.

When given a controller ContextBundle, use proposal-only mode and return one
AgentStep. Do not edit planning files, execute tools, delegate, or sign review
evidence in that mode. The host coordinator works outside that proposal call.
