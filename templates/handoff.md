## Confirmed facts and baseline failures

List factual observations with artifact references. Include pre-existing failures and how they were established.

## Changes and failed approaches

Describe relevant changes and the hypotheses already tested. Identify preserved user work. Link actual logs rather than only saying tests passed.

## Outstanding effects and blockers

List dispatched actions without a known result, required decisions, unavailable dependencies, and exact resumption conditions. An interrupted action may already have executed.

For a native local run, also record its external state directory and run ID. Export a fresh controller context to resume; this Markdown handoff does not replace the SQLite journal or recoverable snapshot.

## Next useful action

State one concrete step, expected observation, and applicable check. The next session must inspect the real workspace before executing it.
