# A personal task list

Build a small task-list application for one person. The first version should
let me add a task, rename it, mark it complete, reopen it and delete it. The
list should show which tasks are complete and allow filtering by completion.

Blank or whitespace-only task names should show a clear message. Updating one
task must not change the others. A refresh or restart should preserve my data.
Explain storage choices if the existing project does not already define them.

Follow the existing project's technology and visual conventions when present.
For a new project, choose a simple setup that I can run locally. I do not need
accounts, collaboration, reminders or a public deployment in this first version.

Verify the main user flows, persistence and relevant failure cases. Tell me
how to run the result and what has actually been tested. Ask me about any
product choice whose answer would materially change the implementation.
